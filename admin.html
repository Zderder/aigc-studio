☁️ 云端同步

启用后将数据同步到 Firebase 云数据库，任何设备打开链接都能看到作品。
基于 Firebase Realtime Database，免费额度充足。

📖 如何获取 Firebase 数据库地址？（首次使用必看）
  1. 访问 Firebase 控制台，用 Google 账号登录
  2. 点击「创建项目」→ 输入项目名 → 其余默认 → 点击「继续」直到完成
  3. 左侧菜单点击「Build」→「Realtime Database」→「创建数据库」
  4. 选择离你最近的区域，安全规则选「测试模式」→ 点击「启用」
  5. 数据库创建后，点击顶部 ⚙️ 规则，改为： { "rules": { ".read": true, ".write": true } }
  6. 回到「数据」标签页，复制上方的数据库 URL（类似 https://xxx-default-rtdb.asia-southeast1.firebasedatabase.app）
✨ 跨设备访问设置完成！
点击上方「下载 config.json」，然后将该文件上传到网站的根目录（和 index.html 同级）。
上传后，所有设备打开网站链接即可看到你的作品。
